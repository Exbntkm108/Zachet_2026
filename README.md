# Zachet_2026
cyber_volunteers/
│
├── app.py                 # Основной файл приложения
├── models.py              # Описание структуры базы данных
├── requirements.txt       # Зависимости (flask)
│
└── templates/             # Папка с HTML-файлами
    ├── base.html          # Базовый шаблон (шапка, навигация)
    ├── index.html         # Главная страница: список волонтёров и рейтинг
    ├── add_volunteer.html # Форма добавления нового участника
    └── log_session.html   # Форма записи проведенного занятия
Как это решает проблему компании:
Скорость: Координатору не нужно искать строку в Excel. Достаточно нажать кнопку «Отметить занятие» напротив имени.
Актуальность: Данные сохраняются мгновенно. Рейтинг на главной странице пересчитывается автоматически после каждого действия.
Аналитика: Сразу видно лидеров (ORDER BY ... DESC) и тех, у кого стоит значение 0 — им требуется помощь или мотивация.
Масштабируемость: Если завтра волонтёров станет 10 000, база SQLite справится, а интерфейс легко дополнить поиском по городу или фильтром по дате.
